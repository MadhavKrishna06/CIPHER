# Prompt Sets

One set per group member. Each set is different, so no two captures contain the
same traffic and no two write-ups describe the same trace.

Every set follows the same shape on purpose:

- three questions the course materials cover well, which should produce grounded
  answers with citations
- one question the materials cover thinly or not at all, which should produce
  either a partial answer or "The course materials do not cover this"
- one quiz interaction

The fourth prompt matters. An answer that declines to invent content is a
correct answer, and it is the clearest evidence that the system is grounded in
the course corpus rather than in the model's own memory. Do not swap it for an
easier question.

Run all five with the internet switch off.

---

## Set 1

1. What is a replay attack?
2. How does Kerberos authenticate a user?
3. What is the difference between a packet-filtering firewall and an
   application-level gateway?
4. What is a SIM swap attack?
5. Quiz: topic `Kerberos`, 3 questions. Answer one correctly and one wrongly.
